Introdução

Sobre a TACO

A Tabela Brasileira de Composição de Alimentos (TACO), 4ª edição, é publicada pelo Núcleo de Estudos e Pesquisas em Alimentação (NEPA) da UNICAMP e reúne dados de composição nutricional de alimentos consumidos no Brasil.

Sobre esta API

Esta é uma API inteiramente estática: cada endpoint é um arquivo JSON pré-gerado e hospedado no GitHub Pages. Não há servidor de aplicação, chave de API, autenticação ou limite de requisições — basta fazer requisições HTTP GET diretamente aos arquivos.

TACO × POF: os identificadores não são equivalentes

Os códigos da POF (usados nas medidas caseiras) são do IBGE e não correspondem aos ids dos alimentos da TACO. Não há equivalência automática entre as duas tabelas — veja a seção Medidas caseiras.

Preparações

Muitos alimentos da TACO descrevem a mesma matéria-prima em diferentes formas de preparo (cru, cozido, grelhado, frito). Cada alimento traz os campos base_name, preparation e qualifiers — por exemplo, "Arroz" / "cozido" / "integral". O endpoint preparations.json lista as preparações reconhecidas pela base.

{{ preparationsData }}

Medidas caseiras

As medidas caseiras (ex.: "1 colher de sopa = 12 g") vêm da Pesquisa de Orçamentos Familiares (POF) 2008–2009 do IBGE, e são indexadas por pof_food_id — um identificador do IBGE, não da TACO.

Os códigos da POF são do IBGE e não correspondem aos IDs da TACO; não há equivalência automática entre as duas tabelas.

Estrutura dos dados

TACO API
│
├── index.json                       metadados e lista de endpoints
├── coverage.json                    cobertura de dados por nutriente
├── foods.json                       os 597 alimentos
│
├── foods/
│   └── {id}.json                    composição completa do alimento
│       └── variants.json            outras formas de preparo (foods/{id}/variants.json)
│
├── categories.json                  lista de categorias
│   └── categories/{slug}.json       detalhe de uma categoria
│
├── preparations.json                preparações reconhecidas
│
└── measures/
    ├── index.json                   índice de medidas caseiras (POF)
    └── {pof_food_id}.json           medidas caseiras de um item POF

Fontes e metodologia

  • Tabela Brasileira de Composição de Alimentos (TACO), 4ª edição — NEPA/UNICAMP.
  • Medidas caseiras derivadas da Pesquisa de Orçamentos Familiares (POF) 2008–2009 — IBGE.
  • Todos os endpoints são arquivos JSON estáticos, gerados a partir dessas fontes e publicados via GitHub Pages — não há atualização em tempo real.
  • Código-fonte e a versão dinâmica em FastAPI: github.com/brolesi/taco.
